# toeslagen-cal

Site which generates an ICAL containing payment dates for Dutch benefits ("toeslagen")

## Development

To run this repo locally, do the following after initially cloning the repo (assuming you have corepack enabled, you do not need to install pnpm yourself)
```bash
pnpm install
```

And to run the development server do the following
```bash
pnpm run dev
```

The site will then be served at [http://localhost:5173/](http://localhost:5173/)
